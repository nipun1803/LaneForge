# Example programs

Ready-to-run programs for `simd_top` (LANES=4, WIDTH=8). These are the three examples from [docs/programming_guide.md](../docs/programming_guide.md). Each one is written in assembly (`*.s`), assembled into hex files by [`scripts/lfasm.py`](../scripts/lfasm.py), and loaded through the `IMEM_INIT` / `DMEM_INIT` parameters.

```sh
make asm     # programs/*.s -> programs/*.hex and *_data.hex
make demo    # assembles, then runs all three and checks the results
```

| Program | Files | What it does | Result | Cycles |
|---|---|---|---|---|
| Vector add | `add.s` → `add.hex`, `add_data.hex` | `mem[2] = mem[0] + mem[1]` in 4 lanes | `mem[2] = 14131211` | 5 |
| Add constant | `add_const.s` → `add_const.hex`, `add_const_data.hex` | add scalar 5 to every lane | `mem[1] = 2D190F06` | 5 |
| Threshold | `threshold.s` → `threshold.hex`, `threshold_data.hex` | keep elements < 5, zero the rest | `mem[1] = 00010003`, mask `0101` | 6 |

`run_programs.v` runs all three, prints each result next to the expected value, and ends with `ALL PASS`.

## Benchmark programs

[`bench/`](bench/) holds the scalar-versus-SIMD benchmark programs for `N = 32` elements at 1, 4 and 8 lanes (W1 add, W2 count below a threshold, W3 masking, W4 `a·X + b`). They are generated by [`scripts/bench.py`](../scripts/bench.py) (`make bench`), which also checks them; assemble one by hand with the matching `--lanes`, e.g. `python3 scripts/lfasm.py programs/bench/w1_add_L8_N32.s --lanes 8`.

## Writing your own

Write a `.s` file (syntax in the [programming guide](../docs/programming_guide.md#the-assembler)) and run `python3 scripts/lfasm.py yourprog.s`. The hex format it produces is one 16-bit instruction per line in `*.hex` and one `LANES*WIDTH`-bit data word per line in `*_data.hex`. Encodings are listed in [docs/instruction_set.md](../docs/instruction_set.md). Unused instruction slots are `HALT` and unused data words are 0, so Icarus's `Not enough words in the file` warning is harmless (`make demo` hides it).
